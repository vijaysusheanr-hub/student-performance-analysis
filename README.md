# Student Performance Analysis

## Overview

This project focuses on analyzing student academic performance using Python, Pandas, and Matplotlib. The analysis was performed on a real-world student dataset containing exam scores and demographic information.

The objective of the project is to identify performance patterns, compare subject-wise scores, and generate analytical insights through statistical analysis and data visualization techniques.

---

## Objectives

- Analyze student performance data
- Compare subject-wise average scores
- Perform statistical analysis on exam results
- Visualize performance trends using charts
- Understand basic data analytics workflow using Python

---

## Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- VS Code

---

## Dataset Information

The dataset contains 1000 student records with the following attributes:

- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch Type
- Test Preparation Course
- Math Score
- Reading Score
- Writing Score

---

## Analysis Performed

The following operations were performed during the analysis:

- Data loading using Pandas
- Dataset inspection using `info()` and `describe()`
- Statistical summary generation
- Average score calculation
- Subject-wise performance comparison
- Top-performing student analysis
- Data visualization using bar charts

---

## Sample Insights

- Reading scores showed the highest average performance among students.
- Math scores had comparatively lower average performance.
- Students who completed test preparation courses generally performed better.

---

## Data Visualization

The project includes visual analysis using Matplotlib, including:

- Average Math Score
- Average Reading Score
- Average Writing Score

represented through bar chart visualizations.

## How to Run the Project

### 1. Clone the Repository

```bash

```

### 2. Open the Project in VS Code

Open the folder in VS Code or Jupyter Notebook.

### 3. Install Required Libraries

```bash
pip install pandas matplotlib notebook
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

### 5. Open and Run

Run the `analysis.ipynb` notebook.
